# GameFledgeAlpha — НЕОН-РАЗЛОМ

Браузерная 3D-игра: полёт сквозь ломающийся неоновый тоннель (three.js + WebAudio, один HTML-файл).

## Запуск

Открыть `index.html` в браузере (нужен интернет для CDN three.js). Или: `python -m http.server` в папке проекта.

## Управление

- ← → ↑ ↓ / WASD / мышь — движение
- P / Esc — пауза
- M — звук вкл/выкл
- Enter — старт / рестарт

## Механики

Секторы-стены с разрывом — пролетай через разрыв, собирай сферы (+50), каждые 300 очков новый уровень: быстрее, другой цвет, выше плотность. Рекорд хранится в localStorage.
